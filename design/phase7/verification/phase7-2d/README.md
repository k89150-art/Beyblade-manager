# Phase 7-2d 整合驗證（瀏覽器）

目的：在真實瀏覽器排版下，以修改後的 `index.html`、`style.css`、`script.js`（原始碼切片）、`collection-view.js` 與真實型錄檔，驗證桌面詳細面板、手機 sheet、P-2 選取身分與刪除前檢查、經由面板的 D1 提示與修改流程。只讀、不連 Firebase、不修改專案檔案。

## 使用的真實程式

與 `phase7-2c/` 相同的切片，另加 `hasUnsavedDomInteraction`（檢查「檢視不算編輯、修改中才算」）。替身同 7-2c。

## 執行

```powershell
node design/phase7/verification/phase7-2d/serve-72d.mjs .
```

開啟 `http://127.0.0.1:4345/harness.html`，結果在 `window.__i72d`。依序執行 390／768／1440 寬 × 深色／米色（390、768 為手機 sheet，1440 為桌面面板）。
