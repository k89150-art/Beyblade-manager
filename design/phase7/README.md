## 重點結論

1. **官方規則已確認的特殊結構**：UX エクスパンドブレード（UX-19、UX-20、UX-21 ヘルズネザー）是固鎖一體型戰刃，不能裝固鎖也不能裝 Tr／Op；Tr、Op 是固鎖一體型軸心，可裝在 BX／UX 戰刃下；UX-16 クロックミラージュ只能用 O 型簡易固鎖；CX 4 件戰刃必須有金屬戰刃；輔助戰刃 G × 主戰刃エクリプス 禁止。
2. **現行程式與官方規則不一致**：UX-21-01 與 Op 軸仍被要求填固鎖；沒有阻擋 UX 擴展戰刃＋Tr／Op、G × エクリプス；簡易固鎖用「尾數 5」判斷而非白名單。
3. **最大技術風險**：儲存資料是從畫面表格收集的（`collectCurrentData`），配置、零件、歷史資料列不保留新欄位。UI 改造必須保留這些表格作為資料來源，加欄位的功能需兩段式部署。
4. **方向**：已定案為 A 工作台骨架＋賽事回合記錄採 C 大按鈕面板（原提案另含 B 的疊層示意，未被選定）。
