# 03｜新版資訊架構

## 使用者的實際工作順序

收藏者與玩家的工作不是「四個獨立表格」，而是一條流程：

```
我有什麼（原裝陀螺＋額外零件）
   → 我能組什麼（組裝配置，受零件數量與組裝結構限制）
   → 實戰結果如何（賽事對局、拆解時的原因紀錄）
   → 外部參考（競賽統計，只看客觀資料）
```

目前網站把前兩步放在同一長頁、賽事與統計各自一頁，零件從哪裡來、被誰使用要自己對照。新架構以這條流程分區，並讓「零件」成為串接各區的主軸。

## 頁面分類（推薦架構）

| 區域 | 內容 | 對應現有功能 |
|---|---|---|
| **首頁（工作台）** | 摘要：原裝陀螺數、零件持有／可用、配置數、進行中賽事；快速動作：新增收藏、建立配置、記錄對局；同步狀態與提醒 | 新增（只讀現有資料） |
| **收藏** | 分頁一「原裝陀螺」：卡片／清單、搜尋、系列與結構篩選、排序、新增（自動／手動）<br>分頁二「零件」：全部零件總覽（來自收藏＋額外庫存）、持有／使用中／可用、被哪些配置使用、新增額外零件 | 收藏、額外零件庫存 |
| **配置** | 分頁一「我的配置」：卡片、搜尋、依結構篩選、複製<br>分頁二「拆解紀錄」：原歷史測試，可還原<br>全域「組裝器」：建立／修改配置 | 配置、Quick Editor、歷史測試 |
| **賽事** | 比賽清單（進行中／已完成）、比賽詳細（對局時間軸、回合記錄、名次） | 賽事 |
| **競賽統計** | 四類排行、上蓋搜尋與詳細頁、來源資訊 | 競賽統計（內容不變） |
| **更多** | 說明 6 頁、主題、帳號、同步中心、管理（僅管理員） | 說明頁、主題、管理員 |

「同步中心」集中顯示：同步狀態、收藏儲存版本列、衝突處理（載入雲端／以我的版本覆蓋）、立即重試、F-04 未儲存資料。發生衝突或有未儲存資料時，在所有頁面頂部以橫幅提示，不再只出現在主頁第一張卡片。

## 導覽

### 手機（底部 5 項）

```
[ 首頁 ] [ 收藏 ] [ ＋組裝 ] [ 賽事 ] [ 更多 ]
```

- 中間「＋組裝」是最常用動作，直接開啟組裝器（底部全螢幕抽屜）。
- 競賽統計移到「更多」第一項，並可從零件詳細頁直接跳轉。
- **需要使用者決定**：AGENTS.md 把「手機底部五項主導覽」列為既有操作契約。上面的新五項會取代現在的「收藏／庫存／配置／競賽統計／賽事」。另一個保守選項是保留原五項，只把「庫存」改名為「零件」。

### 桌面

- 左側窄導覽（可收合，沿用 `beybladeDesktopNavCollapsed`）。
- 頂列：全域搜尋（陀螺、零件、配置、比賽一起搜）、同步指示燈、帳號選單、「建立配置」主要按鈕。
- 收藏、零件、配置採「清單＋右側詳細面板」，不需要跳頁或彈窗就能看細節。

## 主要操作流程

### 1. 新增收藏（手機）

1. 收藏 → 右下「＋」→ 底部抽屜。
2. 輸入型號（沿用即時預覽）。共用型號出現候選卡片；套組顯示「將加入 N 顆」。
3. 確認後回到清單，新卡片短暫高亮。
4. 找不到型號 → 抽屜內直接切到手動模式，欄位依選擇的結構出現（見 01 與組裝器）。

### 2. 建立配置

1. 任何頁面按「＋組裝」。
2. **先選結構**（或由選的第一個零件推斷）：標準三件式／CX 三件戰刃／CX 四件戰刃／戰刃一體式固鎖／固鎖一體式軸心。
3. 依結構出現對應的零件槽，每個槽顯示可用數量；用完的零件灰階但仍可看到「被哪個配置使用」。
4. 即時提示：庫存不足、組裝規則（只用官方確認的規則；待確認的只提示不阻擋）、與拆解紀錄重複。
5. 儲存 → 寫入與現在完全相同的 9 欄 `cells`。

### 3. 拆解配置

1. 配置 ⋯ →「拆解」→ 選原因（5 個既有選項）＋備註。
2. 「打錯，不記錄」直接刪除；其他原因進入「拆解紀錄」，可再「還原」。

### 4. 賽事記錄

1. 賽事 → 新增比賽 → 進入比賽詳細。
2. 「下一場」：選對手、3 顆陀螺（從配置挑選或自填），或標記輪空／對手未到。
3. 對局內「記錄一回合」：大按鈕選勝／負與 X／O／B／S，陀螺從本場 3 顆中選。
4. 修改對局改為一個面板，取代連續 `prompt()`；草稿、衝突對照規則不變。
5. 比賽完成 → 顯示計算名次，確認後鎖定。

## 各功能之間的關係

```
官方型錄（唯讀 JSON） ──自動帶入──▶ 原裝陀螺（beybladeTable）──┐
                                                          ├─▶ 零件總覽（計算，不儲存）
額外零件（partTable）───────────────────────────────────────┘        │
                                                                   ▼
組裝規則（新增的唯讀資料）────────────────────────────────▶ 組裝器 ──▶ 配置（configTable）
                                                                   │       │
                                                    拆解（原因）◀────┘       └─▶ 賽事對局選陀螺（tournamentRecords，文字快照）
                                                       │
                                                       ▼
                                                拆解紀錄（historyTable）──還原──▶ 配置

競賽統計（唯讀 JSON，獨立）◀── 零件詳細頁連結（只導覽，不混入個人資料）
```

- 零件總覽、首頁摘要、「被誰使用」都是從現有資料計算，不寫回 Firestore。
- 組裝規則是新增的唯讀資料檔（建議 `assembly-rules.json`），不放進使用者文件。
- 競賽統計與個人資料只做導覽連結，不混合計算（D-008、D-011）。

## 不在本架構內改變的事

- Firestore 路徑、欄位、`cells` 版面、交易流程與版本列文字。
- 官方型錄、名稱對照、競賽統計資料與歷史快照。
- 深色／米色雙主題（D-001）；兩主題只換色彩 token。
- 說明頁內容與管理員唯讀權限。
